Estadísticas para aprender de cada publicación.

Oficina Gratis — Analítica es una herramienta de uso exclusivo del administrador del canal Oficina Gratis para consultar sus estadísticas oficiales de YouTube.

Qué hace la aplicación

Utiliza YouTube Data API y YouTube Analytics API para consultar información del canal, visualizaciones, tiempo de reproducción, interacciones y evolución de suscriptores.

El acceso actual es de solo lectura. No permite subir vídeos, modificar contenido ni publicar comentarios. La autorización requiere el consentimiento del titular a través de Google.

Dónde se procesan los datos

Las credenciales y los informes se guardan en un servidor privado del administrador. Este sitio es informativo: no muestra estadísticas privadas ni permite conectar cuentas de visitantes.

La aplicación no está abierta al registro de terceros.
